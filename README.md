## What it is

C/C++ · Rust · Assembly · Kernel · Embedded · Zig · GPU · Reverse engineering · Build systems — each skill is a compact SKILL.md teaching an agent *how to reason correctly*, backed by compiled examples and evals.

- **124 skills** · **32 domains** · **65 source-backed** · **177 primary sources** · **56 traced claims**
- esearch/ documents 55+ real, source-traced AI-agent failures in low-level code

## Why it exists

AI agents writing C, Rust, or assembly fail in predictable ways — they trust "it compiles", guess ABIs, skip verification. This repository fixes exactly those failures.
